# Fictional example: AeroDock Mini

This example is intentionally fictional. It demonstrates configuration and offer boundaries without representing a real company or product.

## Product concept

A portable indoor air-status device is sold as:

- **Single:** portable device and mobile app
- **Desk Kit:** portable device plus a powered desk dock with an always-on display

## Boundary example

| Capability | Single | Desk Kit |
|---|---:|---:|
| Portable device | Yes | Yes |
| Mobile app | Yes | Yes |
| Desk dock | No | Yes |
| Always-on desk display | No | Yes |
| Dock-powered continuous mode | No | Yes |

The example exists to test Page Boundary Matrix behavior. All facts are fictional and must not be reused as market or category knowledge.
