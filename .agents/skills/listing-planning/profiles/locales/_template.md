# Locale profile template

## Identity

```yaml
locale_id:
language:
script:
market_defaults:
```

## Language mechanics

- punctuation and spacing
- capitalization
- numerals
- date and time
- decimal and thousands separators
- currency display
- unit display
- title and body copy constraints
- native review requirements

## Search language

State only the language and script to research. Do not store a permanent keyword list without category, channel, and project evidence.

## Prohibited content

Do not define personas, product priorities, preferred features, residential scenarios, or purchase motivation in a locale profile.
