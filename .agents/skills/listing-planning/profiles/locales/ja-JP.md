# ja-JP locale profile

## Language

- Japanese
- Japanese punctuation and full-width conventions where appropriate
- Native Japanese copy review required for consumer-facing text

## Formatting

- Currency commonly shown with the yen symbol and no decimal fraction unless the channel specifies otherwise
- Date style should match the channel and document purpose
- Use metric units unless a verified product or channel requirement says otherwise

## Copy QA

- Avoid literal translation structure
- Keep terminology consistent across title, bullets, images, specifications, and support copy
- Check line breaks and text density on mobile
- Research search language for the selected category and channel

This profile does not define consumer needs or product scenarios.
