# Generic marketplace profile

## Use when

The requested platform has no maintained channel profile.

## Required capture

- brand-editable versus platform-controlled regions
- page sequence
- field names and limits
- media support
- variant structure
- comparison support
- mobile behavior
- approval and moderation rules

When a module or field type cannot be proven, record `UNKNOWN`. Do not rename it as another marketplace/DTC/retailer module by analogy.

Create a project-specific Channel Capability Map before slot planning.
