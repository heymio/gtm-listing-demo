# EU region overlay

## Use when

The target market is in the European Union or the project explicitly requires an EU-level review.

## Verification topics

Use current official sources to determine which requirements apply to the specific product, offer, data flow, packaging, service, and channel. Review may include product conformity/labeling, privacy, connected-service disclosures, environmental/packaging obligations, warranty/consumer information, accessibility, and advertising claims.

EU-level checks do not replace country-market research, locale-specific copy, marketplace-site validation, or category evidence.

Do not infer a single EU consumer persona, feature preference, use scenario, or keyword set from this overlay.
