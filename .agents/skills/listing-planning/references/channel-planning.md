# Channel planning

Select the current channel profile, verify brand-controlled versus platform-controlled regions, and capture current account/site capability before slot planning.

Separate Platform Capability evidence from Frontend Visual evidence. Official documentation may establish a supported feature family but does not prove the current consumer-facing shell or exact account entitlement.

When native shell fidelity cannot be supported later, Hardening must use a clearly labeled Content Review Demo instead of inventing channel chrome.
