# Global Planning QA

Before Production Handoff, confirm:

- market, locale, region overlay, channel/site, category, offer, and page target remain separate;
- Product Truth and claim boundaries are evidence-backed;
- VOC remains an independent evidence stream;
- market/category implications cite project evidence rather than country stereotypes;
- `Message != Module` and current channel capability/module structure is verified;
- Gallery/media and enhanced-content/page-region roles remain separate when their final role differs;
- **priority proof coverage is not the Complete Demo-Required Production Set**;
- every final Demo slot/module/region has a current Asset ID or explicit blocked state;
- every current Asset ID has exactly one Evidence Mode;
- every current Asset ID has exactly one Page Visual System direction;
- neighboring directions avoid accidental full-signature repetition, unless intentional repetition is documented;
- no Project State, auditor result, delivery gate, or parity narration leaked into the Production Handoff.

Planning QA evaluates the completeness and integrity of the handoff. It does not perform physical-file verification or final delivery hardening.
