# Channel profile template

## Identity

```yaml
profile_id: channel-id
channel_type: marketplace | retailer-pdp | dtc-product-page | other
site_or_platform:
```

## Verify before use

- current editable areas
- actual account or retailer capabilities
- module names and limits
- image, video, text, and interaction constraints
- desktop and mobile rendering
- ownership of platform-generated versus brand-controlled content

## Brand-controlled slots

List only areas the brand can edit.

## Module or component families

Record exact current names. Use `UNKNOWN` when the capture or account cannot prove the type.

## Content roles

Define the purpose of each slot: identity, summary, proof, scenario, comparison, objection handling, conversion, or specification.

## Mobile behavior

Document crop, order, scrolling, interaction, and responsive constraints.

## Prohibited assumptions

Do not store product-category benefits, consumer personas, or permanent market claims in a channel profile.
