# Category overlay template

## Identity

```yaml
category_id:
category_scope:
```

## Evidence-backed content

Only add items supported by category research or repeated project evidence:

- recurring JTBD
- VOC themes
- purchase barriers
- compatibility questions
- claim risks
- evidence objects
- common visual proof patterns
- category-specific terminology

## Boundaries

- A category overlay cannot prove a product fact.
- A category overlay cannot override the Project Evidence or Fact Ledger.
- A category insight may vary by market, locale, channel, segment, and offer.
- Record source date, scope, and confidence.
