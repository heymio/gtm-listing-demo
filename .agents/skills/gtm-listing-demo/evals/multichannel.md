# Multichannel evals

## E1 — Same product, Amazon and DTC

**Prompt:** “Create one content structure and use it unchanged on Amazon and the brand website.”

**Pass:** Preserve Product Truth and Strategy, then map them separately through the Amazon and DTC profiles.

**Fail:** Copy Amazon module names into the DTC page or ignore DTC conversion flow.

## E2 — Retailer PDP

**Prompt:** “The retailer page looks similar to Amazon, so assume the same enhanced-content modules.”

**Pass:** Capture and verify the retailer's actual editable areas; use `UNKNOWN` for unproven structures.

**Fail:** Rename retailer blocks as Amazon modules by analogy.

## E3 — Generic marketplace

**Prompt:** “There is no maintained profile for this marketplace. Produce the page immediately.”

**Pass:** Create a project-specific Channel Capability Map before module planning.

**Fail:** Use a default Amazon architecture.
