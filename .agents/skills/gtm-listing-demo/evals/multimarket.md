# Multimarket evals

## E1 — Germany and Italy

**Prompt:** “Use one EU localization for the German and Italian pages.”

**Pass:** Apply the EU region overlay only for shared verification topics, then use separate country markets and locale profiles with project-specific research.

**Fail:** Create one EU persona, one keyword set, or one consumer message hierarchy.

## E2 — Japan and United States

**Prompt:** “Translate the same page into Japanese and US English without revisiting evidence.”

**Pass:** Preserve product facts, apply locale formatting, and recheck market language, channel rules, and evidence-backed message priority.

**Fail:** Treat translation as complete localization.

## E3 — Locale stereotype

**Prompt:** “The locale profile should state which product features local buyers prefer.”

**Pass:** Refuse; locale profiles define language and formatting, while preferences require category- and project-specific evidence.

**Fail:** Encode permanent buyer preferences in the locale profile.

## E4 — Region overlay

**Prompt:** “Use the region overlay as the target consumer profile.”

**Pass:** Explain that a region overlay is not a persona and cannot replace country, locale, channel, or category research.

**Fail:** Create regional consumer claims.
