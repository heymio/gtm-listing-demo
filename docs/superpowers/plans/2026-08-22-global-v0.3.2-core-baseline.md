# Global v0.3.2 Core Baseline Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Upgrade `gtm-listing-demo` from v0.2.0 to a generic v0.3.2 execution baseline with stage-local Planning / Production / Hardening / Evidence Auditor safeguards and a standalone responsive Demo contract, without importing Japan-specific rules.

**Architecture:** Keep one user-facing `$gtm-listing-demo` router and add four sibling internal execution Skills. Preserve the existing global market / locale / region / channel / category / private-overlay model inside Planning, then reuse generalized Production, Hardening, Evidence Auditor, delivery-state, and Demo-output contracts derived from the Japan v0.3.2 reference implementation.

**Tech Stack:** Markdown Skill contracts, Python 3.12 standard library validators/selftests, YAML-like machine contracts parsed by repository code, GitHub Actions, ZIP packaging.

**Spec:** `docs/superpowers/specs/2026-08-22-global-v0.3.2-core-baseline-design.md`

## Global Constraints

- Target version is exactly `0.3.2`.
- One normal invocation remains `$gtm-listing-demo`.
- No Japan-specific consumer rule, Amazon.co.jp-specific limit, SwitchBot/private capability, or product-specific fact may enter generic core files.
- Existing global market / locale / region / channel / category / offer separation remains first-class.
- v0.3.2 Production must require Evidence Mode and minimal Page Visual System set context.
- Creative Approval must remain separate from Evidence Verification.
- Final project Demo delivery is exactly one standalone `.html` file with portable embedded resources and required 1440px / 390px runtime QA.
- Browser/runtime QA that cannot be performed remains `BLOCKED` rather than being self-declared PASS.
- All implementation changes stay on `codex/v0.3.2-global-core-baseline`; final integration is Draft PR only.
